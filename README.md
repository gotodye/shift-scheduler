# 排班系統

以半小時為區間、可拖拉的排班工具，能匯出成阿波羅打卡系統的 Excel 匯入檔。

## 第一階段（目前）— 本機版

- 純網頁，無需安裝。用瀏覽器打開 `index.html` 即可使用。
- 資料存在瀏覽器本機（localStorage）。**這階段只在你自己這台電腦、這個瀏覽器保存**，還沒有多人共用。
- 匯出 Excel 需要能連上網（會載入 SheetJS 元件）。

### 功能

- 五個單位分頁：印尼、越南、泰國、菲律賓、客戶審查。
- 人員管理：每人含**工號**（匯出必填）與姓名。
- 單日 48 格（半小時）拖拉排班，可快速切換日期。
  - 空白處拖拉 = 建立班別
  - 拖曳整條 = 調動時段
  - 拉兩端 = 改上下班時間
  - 點班別 = 編輯精確時間 / 刪除
  - 一人一天可多段班（中間空檔匯出時自動變休息時間，最多 3 組）
- 快速工具：班別範本、套用範本到全組、複製某日、清空當日。
- 休假：「休」＝整日休假；或切換筆刷到「休假」拖出某個時段的休假／不可上班（可像班別一樣調整）。
- 匯出阿波羅打卡檔（工作表「匯入檔」，欄位依官方範本）。
- 上傳打卡比對：讀入阿波羅「上下班紀錄」Excel，用工號＋日期自動比對排班，列出遲到／早退／未打卡／休假日出勤／未排班出勤等差異，可設容許誤差、只看異常、匯出差異清單。

### 匯出規則

- 有排班 → `W0001 上班` + `B001 客服班` + 上下班時間；中間空檔轉成休息時間。
- 標記休假 → `H0001 休假日`。
- 沒排班也沒標休假 → **不輸出該列**（代表可臨時加班）。

## 第二階段（已接上）— 多人雲端

- Google 登入（Firebase Authentication），只有被授權的帳號能使用。
- 班表、人員、範本存 Firestore，多人即時同步。
- 依單位分權限；`gotodye@gmail.com` 為首位管理員，可在「使用者」管理其他人與各自可編輯的單位。
- 每段班別各存一筆（`shifts/{日期__人員}`），避免多人互相蓋掉。

### 首次上線設定（Firebase 主控台，做一次）
1. Authentication → Sign-in method → 啟用 Google。
2. Firestore Database → 建立資料庫（正式版、asia-east1）。
3. Firestore → 規則(Rules) → 貼上 `firestore.rules` 的內容 → 發布。
4. Authentication → Settings → 授權網域(Authorized domains) → 新增 GitHub Pages 網域（例如 `gotodye.github.io`）。localhost 預設已授權。

### 開發 / 測試
用了 Google 登入後要透過網址（localhost 或 Pages）開，不能 file:// 雙擊。本機測試可跑：
`python -m http.server 8931`（在專案資料夾），再開 http://localhost:8931 。
